# K76 Business Solutions — Corporate Website

A premium, immersive single-page company website for **K76 Business Solutions**, built around a real-time 3D scene: extruded glossy red K76 typography, a cursor-reactive particle field, floating metallic objects and a GLSL liquid orb, all choreographed by scroll.

Static frontend only. There is no backend, database or API. All content lives in `src/data/`.

## Stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · Three.js · React Three Fiber · drei · @react-three/postprocessing · custom GLSL · GSAP + ScrollTrigger + SplitText · Framer Motion · Lenis · Lucide

## How it works

- **One persistent WebGL stage** (`src/scenes/HeroScene`) is fixed behind every section and lazy-loaded into its own chunk while the loader plays.
- **Scroll choreography:** each section has a keyframe in `SCENE_KEYFRAMES`. ScrollTrigger scrubs a shared, non-React `sceneState` (`src/lib/store.ts`) between keyframes. The 3D components damp toward that state every frame, so objects travel between sections instead of fading in and out.
- **Particles:** a single-draw-call `THREE.Points` with custom shaders, plus a CPU spring simulation. The cursor repels particles, holding the pointer down attracts and swirls them, and scroll velocity smears them. The metallic shards use `InstancedMesh`.
- **Loader:** a 2D-canvas particle convergence and a stroke-drawn K76 (real Anton outlines, generated by `scripts/make-logo-path.mjs`). It hands over to the 3D intro, where the particles burst outward from the centre.
- **3D type:** `src/assets/fonts/anton-k76.typeface.json` holds only the K, 7 and 6 glyphs (about 2 KB), generated by `scripts/make-typeface.mjs`.

## Performance and accessibility

- Device tiers (`src/lib/quality.ts`) set the particle and shard counts, orb detail, DPR, shadows and post-processing. `PerformanceMonitor` steps quality down at runtime if FPS drops.
- Rendering pauses when the tab is hidden. All geometries and materials are disposed on unmount.
- Touch devices get no custom cursor or magnetic effects. Services become a tap accordion.
- `prefers-reduced-motion` turns off Lenis, the intro, scrubbed motion and the scene's idle animation. The horizontal timeline falls back to a vertical list.
- If WebGL is unavailable, an error boundary shows a static red-glow backdrop.

## Deploy (Vercel)

Import the repo in Vercel. The framework (Vite) is auto-detected, and `vercel.json` sets long-lived caching for hashed assets. For Hostinger, upload the contents of `dist/`.
